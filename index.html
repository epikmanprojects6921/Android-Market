Help

How do I install an app?

Tap Install on any app. Your browser downloads an APK file. Open it on your Android phone, allow installs from this source if Android asks, then tap Install.

What does “Requires YouTube Proxy” mean?

The YouTube versions need YouTube Proxy to work. Install YouTube Proxy first, then YouTube.

How does Save work?

Tap + Save on an app to add it to My Library. If you’re signed in, the list belongs to your account.

Where is my account stored?

Accounts and saved apps are stored only in this browser, on this device. They aren’t synced to other devices.

Something isn’t working

Try reloading the page. App files are hosted by their developers, so a download can fail if their server is down.
