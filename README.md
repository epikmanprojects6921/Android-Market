Version 0.2 is mostly about making the site feel finished. Several things that looked right but didn't work are now fixed, and the biggest addition is a full translation system. Search and the home page layout also got attention.

# Search finally works!

In the first version the search box was only for show: you could type in it, but nothing happened. It now works. As you type, the page switches to a results page titled "Search results for…", and the results update with every keystroke. It looks through app names, developer names and version numbers, so searching for a version number such as "4.3.9" or "0.21" brings up the app that has it. Each result has its own Install button, and if nothing matches you see "No apps found." Clearing the box takes you back to the home page.

# The home page is cleaned up!

The home page had a few layout problems after earlier changes. When the Versions button and the Unofficial tile were removed, the three category buttons ended up shorter than the grid of promo tiles beside them, leaving an awkward white gap. The buttons now stretch to match the height of the tiles, and the last tile expands to fill its row. The category icons were also moved inside the white area, so they no longer hang over the edge of the page.

Two smaller layout fixes round this out. The page now always reserves room for the scrollbar, so the layout doesn't shift sideways when you move between short pages and long ones. The colored section tabs on the right edge also no longer stick out past the page, which removes a source of sideways scrolling.

# A whole translation system

The language picker in the footer used to do nothing. It is now a real selector with English, Español, Français, Deutsch and Nederlands. Choosing a language translates the entire interface: the navigation, the banner, the promo tiles, the descriptions, the info boxes, the sign-in form, the error messages, the version labels and the footer credits.

Text that appears while you use the site, such as search results and error messages, is translated as it shows up. Your choice is remembered between visits. The only things left alone are app names, developer names, version numbers and the logo.
